# 中文字体与排版

原版 TMP 字体图集只覆盖拉丁字符，直接替换中文会出现方块或空白。补丁随包提供 `SourceHanSansSC-Regular.otf`，SHA-256 为 `f1d8611151880c6c336aabeac4640ef434fa13cbfbf1ffe82d0a71b2a5637256`，按 SIL Open Font License 1.1 再分发。

插件启动时：

1. 使用 `AddFontResourceEx(..., FR_PRIVATE)` 将字体注册到当前游戏进程，不修改系统字体；
2. 从 OTF 为当前 746 条译文所需字符预生成静态 TMP SDF 图集；
3. 将该图集加入原 TMP 字体的 fallback 列表；
4. 为 legacy `UnityEngine.UI.Text` 使用动态 Unity Font；
5. 把游戏原动态 TMP 字体固定为静态，避免它们尝试向只读图集写入新字形。

基线实测生成 1,555 个字符/字形，日志为 `Chinese font ready: True`，未再出现中文缺字警告。译文增加新字符后必须重新构建并复查实机日志。
