# 公开仓库数据边界

## 已排除内容

公开仓库不包含以下游戏固有数据：

- Unity 资源封包、程序集和可执行文件；
- 提取的 TextAsset、序列化字符串、IL 字符串、JSON 模板；
- 贴图、联系表、音频清单及其他审计导出物；
- 英文对白、收藏品、EULA 和界面原文表；
- 游戏安装路径、运行日志和本机调试缓存。

这些内容既不参与 Git 提交，也由 `.gitignore` 设置防误提交规则。

## 仓库保留内容

补丁必须携带自己的中文译文。`translation/strings.csv` 共 746 条规则，只保留：

- 补丁内部 ID；
- `exact`、`prefix` 或 `suffix` 匹配模式；
- 场景/对象层级定位；
- 原文 SHA-256 与 UTF-16 长度；
- 中文译文和审校状态。

SHA-256 是不可逆的定位摘要，不还原或替代游戏原文。运行时表只把中文译文做 Base64 编码，以安全承载制表符和多行内容；Base64 不作为隐私或版权保护手段。

## 构建边界

编译插件时需要从用户合法安装的游戏目录引用 Unity/游戏程序集，但构建脚本只读取它们，不复制到 `payload` 或 `dist`。最终 ZIP 只包含 BepInEx、补丁插件、哈希键译文表、字体、配置和许可证。
