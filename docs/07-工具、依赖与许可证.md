## 构建依赖

- Windows PowerShell 5.1 或 PowerShell 7；
- 可构建 `netstandard2.1` 的 .NET SDK；
- 用户合法安装的 Erratum，用于只读引用其 Unity 程序集。

仓库不附带 Python、AssetStudio、UnityPy、离线 wheel 或任何游戏文件。翻译编译器使用 PowerShell/.NET 标准库，不需要额外包。C# 构建关闭 PDB、启用确定性编译并用 `PathMap` 隐藏本机源码绝对路径。
