# 技术路线与补丁结构

## 运行方式

补丁采用 BepInEx 5.4.23.5 x64 加自制 `ErratumChinesePatch.dll` 的运行时覆盖方案。玩家将 `payload` 内容复制到 `Erratum.exe` 同层后正常启动游戏；补丁不改写 `resources.assets`、`sharedassets*.assets`、关卡文件、程序集或存档。

插件读取 `BepInEx/plugins/ErratumChinesePatch/Localization/strings.tsv`，在对话、交互、提示和界面文本显示前应用翻译。场景加载后还会周期性扫描静态 TMP/legacy UI 文本，以覆盖启动早于插件回调的对象。

## 哈希匹配

公开仓库不保存英文原文。每条规则只包含场景、对象层级、匹配模式、原文 SHA-256、UTF-16 长度和中文译文。运行时对游戏提供的当前文本计算 SHA-256：

- `exact`：按完整文本哈希匹配；
- `prefix` / `suffix`：按记录长度截取固定部分后计算哈希，并保留运行时追加的动态内容；
- 未匹配文本原样返回，不会写回游戏文件。

尾随 `\r` 会在匹配前临时剥离、替换后恢复，以兼容游戏用 CRLF 解析对白脚本的行为。

## 中文字体

插件将随包 Source Han Sans SC OTF 私有注册到当前进程，并按已编译译文字符集生成静态 TMP SDF 图集。legacy UI 使用动态 Unity Font；原 TMP 字体通过回退列表取得中文字形。详情见 `06-中文字体与排版.md`。

## 目录职责

| 路径 | 用途 | 进入发布包 |
|---|---|---|
| `translation/strings.csv` | 哈希键中文译文源表 | 编译后进入 |
| `plugin-src/` | 运行时插件源码 | 编译后进入 |
| `tools/` | 校验、编译和打包脚本 | 否 |
| `payload/` | 游戏根目录直解压文件树 | 是 |
| `docs/` | 技术与验证记录 | 否 |
| `dist/` | 本地生成的 ZIP | 不提交 Git |

`extracted/`、游戏程序集和开发期离线工具链均不属于公开仓库，已由忽略规则阻止误提交。
